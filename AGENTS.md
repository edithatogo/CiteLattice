# CiteLattice agent context

Read `conductor/index.md`, `conductor/requirements.md`, the active track plan, `docs/versioning.md`, and only the relevant Rust contract files. CiteLattice is a single-developer, coding-agent-friendly repository.

- Contract-first: source -> method -> result table -> scientific scene -> render -> workbook/report/package; every transition retains exact provenance and rights.
- CSL-JSON is the canonical bibliographic interchange. An analytical projection is not a replacement. Never silently invent missing citations, references, affiliations, sources or study linkages.
- No claim of bibliometrix/PyBibX parity or scientific superiority without independent fixtures, method definitions, benchmark data and observed results.
- Fail closed on incompatible major versions, sequence gaps, hash mismatches and disallowed disclosure.
- Default network, remote inference, telemetry and model downloads are OFF. Keep restricted abstracts and metadata out of logs, hidden visual layers and unapproved exports.
- Prefer well-maintained existing dependencies, with rationale and benchmark; keep heavyweight options feature-gated.
- Every ordinary change uses one scoped task, test, CI, and PR. Existing authority covers routine edits/merge after checks. Seek fresh consent only for destructive changes, restricted data sharing, new permissions, registry publication and scientific method changes.
- Conductor tracks are plans, not evidence of implementation. No automatic hundreds-of-issues sync, unnecessary panels or duplicated status receipts. Keep CI as evidence.
