# Evidence-linked beyond-frontier scientific imaging

Research target rather than established frontier performance. Every quantifiable mark must link to authoritative table rows or a membership artifact, with a reproducible transform and exact source revision.

Mandatory scientific dimensions: coordinate/reference system, temporal alignment/cluster identity, uncertainty divided into sampling, source coverage, identity, model and layout, aggregate conservation across semantic zoom, parameter sensitivity and source/method multiverse comparisons.

Targets include citation/co-author/term networks; thematic map and evolution; geographic collaborations; three-field Sankey; RPYS; longitudinal research-system flows across funding/publications/trials/patents/policy; interactive citation evidence drill-down. Animation must have a static equivalent and not create interpolated false observations.

Vega-Lite JSON and Plotters/SVG for low-cost charts. Optional WebGPU/wgpu, dimensionality reduction, 3D/LOD only after benchmarks and perception tests show advantage. Quantitative geometry is computed from actual tables, never fabricated by generative models. Every downloadable image includes accessible tabular and narrative equivalents.

Risk controls: XHTML/HTML escaping, CSV formula injection, SVG script/event stripping, privacy leakage through tooltip/labels/hidden layers/embedded assets, graphic overlays suggesting unwarranted significance, truncated axis, projection distortion and accessibility contrast/keyboard tests.

Renderer receipt binds scene, backend, assets/fonts, geometry checks, source tables, output hashes and reproducibility class.

## Risk register: completeness and integer safety

Every generated temporal plot must either include all periods or prominently
declare the omitted population and selection policy in a machine-readable
scene contract. A fixed arbitrary first-N crop is prohibited. Use checked wide
arithmetic for heights/scales and reject excess marks before writing files.
For >512 annual periods, prefer an explicit aggregation/LOD adapter with
membership conservation evidence; do not pretend that a huge SVG is usable.
A graph projection from raw author strings must carry hard complexity budgets,
and cannot be presented as disambiguated identities.

## Implemented annual scene slice — validation pending

The `citelattice-visualize` crate creates a small evidence-bearing annual-production scene from the same typed annual counts used by Parquet and XLSX. Each bar refers to one exact `year` row key, and the scene is separately fingerprinted from its SVG rendering. Values above JavaScript's maximum safe integer are **rejected**, not rounded in Vega-Lite or `EvidenceMark.value`. Source totals and distinct ascending years are validated before graphics generation; caller approval is required but does **not** independently establish rights. The direct renderer does not do clustering, semantic zoom or temporal network layouts, and its geometry/disclosure checks are explicitly self-checks, not independent validation.
