# CiteLattice

Contract-first Rust bibliometrics, scientometrics and evidence-linked scientific visualisation.

This repository is being initialised from the `bibx` design.2 source artifact. The canonical project name is **CiteLattice**. Design declarations do not establish implemented algorithms, validated metrics or beyond-frontier performance.

Canonical bibliographic interchange remains CSL-JSON. Heavy analytical, graph, inference and rendering dependencies are optional. Searchright owns evidence acquisition and review state; CiteLattice owns scholarly analysis and analytical outputs.

The standards, compatibility fixtures, dependency decisions and Conductor workstreams will be committed on a scoped design branch before promotion. No package publication is implied.
