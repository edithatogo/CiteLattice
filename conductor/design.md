# Contract-first architecture

Source (CSL-JSON, Searchright, licensed adapter) → evidence & rights envelope → entity resolution → Polars/Arrow analytics + graph topology → versioned scientific method registry → authoritative typed tables → evidence-backed scene → SVG/PNG/HTML → XLSX/PDF/RO-Crate.

Method and source change invalidates dependent results. Palette/font change invalidates rendering only. Rights revocations must invalidate exposed derived assets, including hover text, hidden visual layers and embedded data.

Default core has no mandatory GPU, local model, provider API, SQL server or remote connection. Heavy backends are feature-gated. Rust's borrowed parse buffers cannot cross async ownership boundaries without promotion; Arrow interoperability is not inherently zero-copy.
