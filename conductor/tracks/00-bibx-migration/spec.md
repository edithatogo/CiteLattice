# Track 00 — Migration and foundation

Import or explicitly reconcile useful original bibx design.2 sources, contracts,
capability coverage and accessible history under CiteLattice names. Retain
source identity, scientific conventions, rights and unsupported states.
The project must have a complete Conductor handshake and a tested native
workspace. Do not replace newer CiteLattice implementations with older sketches.

Acceptance: original archive with content identity; manifest of each useful
file and its equivalent, replacement, justified exclusion or pending migration;
complete native workspace build/tests and API parity or documented intentional
differences. Scientific certification is outside this migration gate.
