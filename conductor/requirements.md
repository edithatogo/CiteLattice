# Requirements (MoSCoW)

| ID | MoSCoW | Completion contract |
| --- | --- | --- |
| CL-001 | Must | Preserve canonical CSL-JSON and exact source provenance independent of analytical projections |
| CL-002 | Must | Searchright JSONL envelope with version negotiation, correction/retraction, rights, idempotency and replay tests |
| CL-003 | Must | Comprehensive outcome coverage register: scientific definition, denominators, inputs, algorithm, independent oracle and maturity per method |
| CL-004 | Must | Separate exact schema, input, entity, method, parameter, implementation, result-table, scene and render revisions |
| CL-005 | Must | Arrow/Parquet typed tables with explicit units, missingness, rights and identities |
| CL-006 | Must | Citation and graph indicator correctness with known-answer, temporal and source-coverage tests |
| CL-007 | Must | Every image mark resolves to rows, semantic transformation and source; safe offline and accessible output |
| CL-008 | Must | XLSX/HTML/PDF/RO-Crate bundles deriving from identical authoritative tables |
| CL-009 | Must | Default-deny network, remote model downloads, telemetry and unapproved restricted exports |
| CL-010 | Must | Small Rust core with opt-in backend dependency features and compatibility evidence |
| CL-011 | Must | CSL-JSON, NDJSON, Arrow IPC, Parquet; CSV with loss receipts |
| CL-012 | Should | RIS/BibTeX/NBIB/PubMed XML/EndNote adapters through existing well-tested libraries |
| CL-013 | Should | GraphML/GEXF, Vega-Lite, SVG/PNG, XLSX, Typst PDF, HTML and PROV/RO-Crate |
| CL-014 | Should | Dimensions cross-domain grants/patents/trials/policy/datasets with entitlement and source coverage |
| CL-015 | Should | Incremental methods and temporal graph equivalence to full recompute |
| CL-016 | Should | Innovate/Voiage as-of historical study with independent utilities |
| CL-017 | Could | GPU/WebGPU, 3D scenes and advanced interactive scientific imaging after proof of benefit |
| CL-018 | Won't | Duplicate Searchright/Sourceright/CiteWeft, claim external FCR/RCR parity or conflate bibliometric interest with causal impact |

Scientific method registration does not establish implementation. Each method requires formula/citation, population, counting rule, missingness policy, independent oracles and release evidence.
